# Weather-app
Weather App is a simple and interactive web application that provides real-time weather updates for any location. Built with HTML, CSS, and JavaScript, it fetches weather data using an API and displays details such as temperature, humidity, wind speed, and weather conditions. The app offers a user-friendly interface for quick and accurate weather information. ☀️🌧️🌍
